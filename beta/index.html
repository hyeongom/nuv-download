Netflix 이전 화·다음 화 수정 · 확장 0.1.7

다음 화는 사용자 테스트에서 작동을 확인했습니다. 이전 화는 목록을 연 뒤 멈추는 경우에 대응해, 이전 회차를 클릭하여 미리보기를 펼치고 재생하도록 보완했습니다. 이전 화의 실제 Netflix 재생 성공 여부는 아직 확인이 필요합니다. PC와 모바일 앱은 다시 설치할 필요 없습니다.

테스트 확장 0.1.7 다운로드

확장 업데이트

  1. 위 ZIP을 다운로드하고 압축을 푸세요. popup.html을 직접 열지 마세요.
  2. Chrome 주소창에 chrome://extensions를 입력하세요. Edge는 edge://extensions입니다.
  3. 개발자 모드 → ‘압축해제된 확장 프로그램 로드’에서 이번에 푼 0.1.7 폴더를 선택하세요. 기존 NUV 확장을 교체하며 확장 ID는 같습니다.
  4. 확장 카드의 버전이 0.1.7인지 확인하고 넷플릭스 영상 탭도 새로고침하세요.

PC 앱의 ‘설치 준비’는 아직 이전 확장 0.1.2를 제공합니다. 이번 진단은 반드시 위 ZIP의 폴더를 로드해주세요.

회차 이동 테스트

  1. 확장의 연결 대상을 NUV 테스트로 선택하고 연결하세요.
  2. 넷플릭스 시리즈를 재생한 뒤 NUV의 Netflix 다음 화와 Netflix 이전 화를 각각 한 번씩 눌러보세요.
  3. 현재 시즌의 첫 화에서 이전 화로 이동하는 기능은 지원하지 않습니다. 시즌은 넷플릭스에서 선택하세요.

문제가 계속될 때 진단 결과 보내기

  1. 넷플릭스 시리즈 영상을 재생하세요.
  2. 브라우저 퍼즐 아이콘 → NUV 브라우저 연결을 여세요. Netflix 탭이 여러 개면 진단할 탭을 고르세요.
  3. 회차 진단 (3초 후)을 누르고 영상으로 돌아가 회차 목록을 펼치세요.
  4. 3초 후 다시 확장을 열어 결과를 확인하고 결과 복사를 눌러 채팅에 붙여넣으세요.

진단은 PC 연결 없이 사용할 수 있습니다. 화면 글자·영상 제목·주소·로그인 정보·쿠키는 결과에 포함하지 않습니다. 버튼과 목록의 구조만 브라우저 세션에 임시 저장하며 자동 전송하지 않습니다.

NUV 키 동작을 테스트하려면 확장의 연결 대상을 NUV 테스트로 고르고 ‘NUV 연결’을 누르세요. 정식 채널은 변경하지 않았습니다.

배포 순서

개발 빌드 → 이 테스트 페이지에서 검증 → 확인된 버전만 정식 페이지에 배포

일반 사용자는 정식 설치 페이지를 이용해 주세요.
