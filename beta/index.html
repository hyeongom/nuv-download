브라우저 확장 0.1.2 다운로드

설치·연결 방법

  1. Windows ZIP을 풀고 NUV 테스트.exe를 실행하세요.
  2. 테스트 앱의 설정 → 브라우저 연결 → 설치 준비·연결 켜기를 누르세요.
  3. Chrome 주소창에 chrome://extensions를 입력하세요. Edge는 edge://extensions입니다.
  4. 처음 설치: 개발자 모드를 켜고 ‘압축해제된 확장 프로그램 로드’에서 NUV가 안내한 폴더를 선택하세요.
  5. 이미 설치: NUV 확장 카드에서 새로고침(↻)을 누르세요. 다른 폴더에서 설치했다면 이번 확장 폴더로 다시 로드하세요.
  6. 확장 팝업에서 연결할 NUV를 NUV 테스트로 고르고 ‘NUV 연결’을 누르세요.
  7. 넷플릭스 영상 탭도 새로고침한 뒤 시리즈 중간 회차에서 이전 화·다음 화를 확인하세요.

확장은 정식·테스트 연결 대상을 선택하는 공용 확장입니다. 두 앱에 동시에 연결하지 않습니다. Android 테스트 앱은 이번에 변경하지 않았습니다.

배포 순서

개발 빌드 → 이 테스트 페이지에서 검증 → 확인된 버전만 정식 페이지에 배포

일반 사용자는 정식 설치 페이지를 이용해 주세요.
