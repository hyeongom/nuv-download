Windows 테스트 앱 다운로드

1.33.0-beta.1 · Windows x64 · NUV 테스트

기존 테스트판을 완전히 종료한 뒤 실행하세요

숨겨진 아이콘의 NUV 테스트 메뉴에서 종료하고, ZIP을 새 폴더에 모두 압축 해제한 뒤 NUV 테스트.exe를 실행하세요. 설정 상단에 1.33.0-beta.1이 표시되는지 확인하세요.

달력과 일정

  1. 메인 화면의 달력 또는 설정 → 달력·일정을 엽니다.
  2. 날짜를 고르고 제목·시간을 입력한 뒤 일정 저장을 누릅니다. 저장한 일정은 선택해서 수정하거나 삭제할 수 있습니다.
  3. NUV 키를 우클릭하고 달력·일정 → 달력 확인 / 일정 추가를 지정하면 키로 바로 열 수 있습니다.

오늘 일정과 지정 시간에 Windows 알림을 표시합니다. NUV가 실행 중일 때만 알림을 보내며 Windows 알림 설정에 따라 표시가 제한될 수 있습니다.

키보드에서 원하는 키만 NUV 키로

  1. 설정 → 키보드 지정에서 연결된 키보드를 선택합니다. 장치가 헷갈리면 키를 눌러 내 키보드 찾기를 사용하세요.
  2. 자판 그림에서 키를 클릭하고 실행할 NUV 키를 선택한 뒤 지정 저장을 누릅니다.
  3. 연결하기를 누르면 지정한 키만 원래 문자 입력을 막고 NUV 동작을 실행합니다. 다른 키와 다른 키보드는 그대로 사용할 수 있습니다.
  4. 설정이나 숨겨진 아이콘 메뉴의 키보드 제어 끊기로 원래 입력으로 돌아옵니다.

F키·Ctrl·Alt·Shift·Windows 등 제어키는 원래대로 동작합니다. NUV 키 우클릭의 키보드 제어 메뉴에서 연결·끊기 동작을 지정하고 F키와 연결할 수 있습니다.

다시 실행하면 연결은 꺼져 있습니다

지정 내용은 저장되지만, 앱을 완전히 종료한 뒤에는 연결하기를 눌러야 적용됩니다.

키보드별 입력 차단 드라이버가 별도로 준비된 PC에서 사용할 수 있습니다. 이번 ZIP에는 제3자 드라이버·설치 프로그램·DLL이 포함되어 있지 않습니다. 드라이버가 없으면 연결하지 않고 기존 입력을 유지합니다.

이번 테스트에서 확인할 내용

일정 저장·알림, 자판에서 키 지정, 선택한 키보드만 동작하는지, 연결 해제와 재실행 후 원래 입력으로 돌아오는지 확인해 주세요.

이번에는 PC 테스트판만 업데이트했습니다. 모바일 앱과 브라우저 확장을 다시 설치할 필요는 없습니다.
