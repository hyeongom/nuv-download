Android 앱 설치하기

NUV 2.8.0 · Android용 APK

다운로드가 끝나면 NUV-Android.apk를 열어 설치하세요. 기존 앱이 있다면 업데이트하면 됩니다.

2.8.0: 계정별 PC 등록·선택·이름 변경·등록 해제와 플랜별 연결 제한, 구독 상태 표시를 개선했습니다.

Windows PC 앱 다운로드

NUV 1.17.0 · Windows 64비트

1.17.0: 영상 제어 탭에서 YouTube·Netflix·Disney+의 재생, 10초 이동, 영상 음소거와 서비스별 동작을 지정할 수 있습니다.

PC에서 압축을 모두 풀고 NUV.exe를 실행하세요. 별도 설치 마법사나 .NET 설치는 필요하지 않습니다.

이번 업데이트는 PC 1.17.0입니다. Android 2.8.0은 그대로 사용하며, 업데이트한 PC에 연결한 뒤 키 설정을 다시 열면 영상 제어 목록이 표시됩니다.

키 설정 → 영상 제어에서 서비스를 선택하세요. PC 브라우저의 영상 영역을 먼저 클릭한 뒤 사용합니다. YouTube 이전 영상은 재생목록 전용이고, 오프닝 건너뛰기는 해당 버튼이 표시될 때 사용합니다.

PC와 휴대폰을 같은 Wi-Fi에 연결한 뒤 앱 설치 후 PC의 ‘휴대폰 등록 QR’을 스캔하세요. 기존 등록 정보가 있으면 앱을 다시 열면 자동으로 연결됩니다.
