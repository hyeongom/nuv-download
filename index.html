휴대폰에 NUV를 설치하고 내 PC를 조작하세요.

Android 앱 설치하기

NUV 2.8.0 · Android용 APK

다운로드가 끝나면 NUV-Android.apk를 열어 설치하세요. 기존 앱이 있다면 업데이트하면 됩니다.

2.8.0: 계정별 PC 등록·선택·이름 변경·등록 해제와 플랜별 연결 제한, 구독 상태 표시를 개선했습니다.

Windows PC 앱 다운로드

NUV 1.23.2 · Windows 64비트

PC 1.23.2: 다음 즐겨찾기로 앱에서 Chrome·Edge 탭으로 이동할 때 브라우저 창이 앞으로 나오지 않는 문제를 수정했습니다. PC만 업데이트하면 됩니다. 확장 0.4.1과 Android 2.8.0은 그대로 사용합니다.

PC에서 압축을 모두 풀고 NUV.exe를 실행하세요. 별도 설치 마법사나 .NET 설치는 필요하지 않습니다.

브라우저 연결 · 처음 설치할 때

PC NUV에서 설정 → 브라우저 연결 → 설치 준비·연결 켜기를 누르세요. PC 준비와 연결 켜기가 함께 완료됩니다.

  1. 안내 창에서 Chrome 확장 관리 주소 복사 또는 Edge 확장 관리 주소 복사를 누르세요. 해당 브라우저 주소창에 붙여넣고 Enter를 누르세요.
  2. 브라우저에서 개발자 모드 → 압축해제된 확장 프로그램 로드를 누르세요.
  3. NUV 안내 창의 설치 폴더 경로 복사를 누른 뒤 폴더 선택 창에 붙여넣고 그 폴더를 선택하세요. popup.html 파일을 직접 열면 연결되지 않습니다.
  4. 브라우저 오른쪽 위 퍼즐 아이콘 → NUV 확장 → NUV 연결을 누르세요.
  5. 양쪽에 ‘연결됨’이 표시되면 영상 제어 키를 눌러보세요. 열려 있던 영상 탭도 자동으로 연결됩니다.

F키 프리셋 사용하기

설정 → F키 단축키에서 이름을 입력하고 프리셋 추가를 누르세요. 새 프리셋은 F1~F12 모두 사용 안 함으로 시작합니다. 같은 이름은 게임 2, 게임 3처럼 번호가 붙습니다. 이름 입력칸은 전환해도 유지되며, 이름 변경을 눌러야 선택한 프리셋에 적용됩니다. 각 F키 배치는 자동 저장됩니다. NUV 키를 우클릭하여 F키 사용 설정 → 다음 F키 프리셋을 지정하세요. 마지막 다음에는 첫 프리셋으로 돌아옵니다. F키로 계속 넘기려면 각 프리셋에 전환 키를 직접 지정하세요. 기존 F키 플랜 조건이 적용됩니다.

통합 즐겨찾기

  1. PC NUV를 1.23.2, 확장을 0.4.1로 업데이트하고 연결합니다.
  2. NUV 키 우클릭 → 창·브라우저에서 즐겨찾기 등록·해제와 다음 즐겨찾기를 지정합니다. 기존 창·탭 즐겨찾기 키도 같은 통합 동작으로 사용됩니다.
  3. 일반 앱에서 등록키를 누르면 현재 창, Chrome·Edge에서는 현재 탭이 등록됩니다. 다시 누르면 해제됩니다.
  4. 다음 키는 창과 탭을 등록 순서대로 함께 이동합니다. NUV 설정 → 즐겨찾기에서 목록·순서·해제를 관리하세요.

확장 팝업에서 등록하거나 이동할 필요가 없습니다. 확장에는 즐겨찾기 화면과 추가 탭 권한 버튼이 없습니다. 탭을 찾기 위한 연결 역할만 합니다. 닫힌 항목은 자동 삭제되며 최소화·다른 탭 이동은 유지됩니다. 일시적으로 연결이 끊긴 탭은 삭제하지 않고 다시 연결될 때 확인합니다.

Chrome·Edge의 탭 제목을 추가 권한 없이 읽을 수 없는 경우에는 등록할 때 PC 창 제목을 사용합니다. 등록한 탭 식별자와 짧은 제목만 해당 PC NUV와 통신하고, 주소나 페이지 내용은 전송하지 않습니다.

일반 브라우저 이전·다음 탭 키도 그대로 사용할 수 있습니다. Android 앱은 PC의 새 동작 목록을 이용합니다.

프리셋 안내와 브라우저 선택

설정 → F키 단축키 → 전환 안내 표시 시간에서 1~60초를 입력하고 적용하세요. 기본값은 5초이며 다시 전환하면 새 프리셋 기준으로 시간이 다시 시작합니다. 키 우클릭 → 웹사이트 열기에서 열 브라우저: 기본 / Chrome / Edge를 선택할 수 있습니다. 휴대폰으로 해당 키를 눌러도 PC에 지정한 브라우저에서 실행됩니다.

기존 확장 업데이트

PC NUV를 1.23.2로 업데이트한 뒤 확장 업데이트를 눌러 0.4.1로 올리세요. 추가 탭 권한 허용 단계는 없습니다. 연결 후 NUV 키에서 즐겨찾기를 사용하세요.

확장 0.2.0 이하에서 처음 바꾸는 경우에는 PC NUV를 최신 버전으로 업데이트하고 설정 → 브라우저 연결 → 설치 준비·연결 켜기를 누르세요. Chrome/Edge 확장 관리에서 NUV의 새로고침(↻)을 누르고 추가 권한 안내가 나오면 확인하세요. 다운로드 폴더에서 설치했다면 PC 안내의 설치 폴더로 다시 등록하세요. 다시 로드하는 것은 확장이며, 영상 탭은 새로고침하지 않아도 됩니다.

이후 확장 업데이트

PC NUV를 켜고 확장을 연결한 뒤 확장 안의 ‘업데이트’를 누르세요. PC가 정식 파일을 확인하고 교체하면 확장이 다시 로드됩니다. 0.2.1부터는 완료 후 첫 키를 누르면 열려 있던 영상 탭의 제어 코드만 자동 갱신합니다. 영상 탭 새로고침은 필요하지 않습니다. 매번 ZIP을 내려받거나 폴더를 다시 등록할 필요는 없습니다.

Netflix 이전 화·다음 화

NUV 키 설정의 영상 제어 → Netflix → 이전 화 / 다음 화를 선택하세요. 정식 확장 연결이 필요합니다. 이전 화는 현재 시즌의 회차 목록을 이용하며 첫 화나 회차를 확인할 수 없는 화면에서는 이동하지 않습니다. 이동 결과를 확인하지 못했다면 잠시 기다렸다 키를 다시 누르세요. 재생이 안정되고 현재 회차를 확인할 수 있을 때 새 요청을 처리하며, 이전 명령을 자동으로 반복하지 않습니다.

브라우저 확장에서 최근 명령의 처리 결과를 확인할 수 있습니다. 건너뛰기는 영상에 해당 버튼이 보일 때 사용할 수 있습니다.

선택형 확장은 아직 스토어에 등록되지 않았습니다. NUV 앱에서 설치 폴더를 준비하는 방법을 권장합니다. 정식 확장 0.4.1 ZIP 별도 다운로드

키를 우클릭하고 오디오 및 미디어 → 영상 전체화면을 선택하세요. 매크로와 모바일 동작 목록에도 같은 항목이 있습니다. PC의 YouTube·Netflix·Disney+ 영상 탭을 먼저 선택해 두세요. 실행 시 영상 창을 앞에 유지하며, 전체화면 해제는 영상에서 Esc를 누르세요.

NUV 확장은 정식 NUV에만 연결됩니다. NUV 테스트 확장은 별도 ID·폴더·업데이트 경로를 사용하므로 정식을 덮어쓰지 않습니다. 정식에는 실행 기록 복사와 진단 도구가 포함되지 않습니다.

Android 2.8.0은 그대로 사용합니다. 기존 키·프로필과 휴대폰 등록 정보는 유지됩니다.
