Android 앱 설치하기

NUV 2.8.0 · Android용 APK

다운로드가 끝나면 NUV-Android.apk를 열어 설치하세요. 기존 앱이 있다면 업데이트하면 됩니다.

2.8.0: 계정별 PC 등록·선택·이름 변경·등록 해제와 플랜별 연결 제한, 구독 상태 표시를 개선했습니다.

Windows PC 앱 다운로드

NUV 1.18.1 · Windows 64비트

1.18.1: F키 실행 오류가 표시되지 않던 문제를 수정하고, 브라우저 확장 설치·연결 안내를 쉽게 바꿨습니다.

PC에서 압축을 모두 풀고 NUV.exe를 실행하세요. 별도 설치 마법사나 .NET 설치는 필요하지 않습니다.

브라우저 연결 · 처음 설치할 때

PC NUV에서 설정 → 브라우저 연결 → 설치 준비·연결 켜기를 누르세요. PC 준비와 연결 켜기가 함께 완료됩니다.

  1. 안내 창에서 Chrome 확장 관리 열기 또는 Edge 확장 관리 열기를 누르세요.
  2. 브라우저에서 개발자 모드 → 압축해제된 확장 프로그램 로드를 누르세요.
  3. NUV 안내 창의 설치 폴더 경로 복사를 누른 뒤 폴더 선택 창에 붙여넣고 그 폴더를 선택하세요. popup.html 파일을 직접 열면 연결되지 않습니다.
  4. 브라우저 오른쪽 위 퍼즐 아이콘 → NUV 브라우저 연결 → NUV 연결을 누르세요.
  5. 영상 탭을 한 번 새로고침하세요. 양쪽에 ‘연결됨’이 표시되면 사용할 수 있습니다.

이미 설치했다면

PC 업데이트 후 설치 준비·연결 켜기를 눌러 확장 파일을 갱신하세요. 브라우저 확장 관리 화면에서 NUV 카드의 새로고침(↻)을 누르고 영상 탭도 새로고침하세요. ZIP 폴더에서 설치했다면 새 ZIP의 폴더로 다시 로드해야 합니다.

브라우저 확장에서 최근 명령의 처리 결과를 확인할 수 있습니다. 건너뛰기는 영상에 해당 버튼이 보일 때 사용할 수 있습니다.

선택형 확장은 아직 스토어에 등록되지 않았습니다. NUV 앱에서 설치 폴더를 준비하는 방법을 권장합니다. 확장 0.1.1 ZIP 별도 다운로드

영상 전체화면은 기존 키보드 단축키 → F로 지정할 수 있습니다. YouTube·Netflix·Disney+의 영상 창에 입력이 가야 합니다. 서비스별 중복 동작은 추가하지 않았습니다.

Android 2.8.0은 그대로 사용합니다. 기존 키·프로필과 휴대폰 등록 정보는 유지됩니다.
