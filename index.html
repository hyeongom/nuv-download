Android 앱 설치하기

NUV 2.6.0 · Android용 APK

다운로드가 끝나면 NUV-Android.apk를 열어 설치하세요. 기존 앱이 있다면 업데이트하면 됩니다.

2.6.0: 연결된 앱만 동작 목록에 표시하고, 일반·미디어·앱 동작을 매크로에 직접 추가하며 메인 화면에서 프로필을 관리할 수 있습니다.

Windows PC 앱 다운로드

NUV 1.14.0 · Windows 64비트

1.14.0: 모바일에서 저장한 설정을 PC에 즉시 반영하고, 연결 상태와 플랜에 맞는 동작만 제공하며 키 테두리 빛 설정을 공개했습니다.

PC에서 압축을 모두 풀고 NUV.exe를 실행하세요. 별도 설치 마법사나 .NET 설치는 필요하지 않습니다.

PC와 휴대폰을 같은 Wi-Fi에 연결한 뒤 앱 설치 후 PC의 ‘휴대폰 등록 QR’을 스캔하세요. 기존 등록 정보가 있으면 앱을 다시 열면 자동으로 연결됩니다.
