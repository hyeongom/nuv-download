Windows PC 앱 다운로드

NUV 1.18.0 · Windows 64비트

1.18.0: 선택형 브라우저 확장 연결·해제를 추가했습니다. 확장을 연결하지 않으면 영상 창을 잠시 앞으로 가져와 실행한 뒤 원래 창으로 돌아옵니다.

PC에서 압축을 모두 풀고 NUV.exe를 실행하세요. 별도 설치 마법사나 .NET 설치는 필요하지 않습니다.

PC 1.18.0 업데이트입니다. Android 2.8.0은 그대로 사용합니다.

설정 → 브라우저 연결에서 설치 안내와 연결·연결 해제를 선택하세요. 설치만으로 연결되지 않습니다. 확장 미연결 시에는 브라우저 안에서 영상 탭을 선택해 두세요.

선택형 확장은 Chrome·Edge 스토어 미등록 테스트 패키지입니다. 현재는 개발자 모드에서 직접 설치해야 합니다. 브라우저 확장 0.1.0 테스트 ZIP 다운로드

지원 대상은 PC 웹의 YouTube·Netflix·Disney+입니다. 건너뛰기 버튼이 표시되는 구간에서 사용하세요. 자동 검증과 연결 통신 검증은 완료했으며, 실제 서비스별 재생 동작은 추가 확인이 필요합니다.

PC와 휴대폰을 같은 Wi-Fi에 연결한 뒤 PC의 ‘휴대폰 등록 QR’을 스캔하세요. 기존 등록 정보는 유지됩니다.
